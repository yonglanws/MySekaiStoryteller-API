## 目标

让宿主 `staged` 流水线生成的 3 分钟短戏在以下维度接近 Project SEKAI 官方活动剧情：

1. 台词形态：句长、两行比例、短反应、省略号/问句、连续说话段。
2. 表演密度：每句动作数、无动作比例、听者反应。
3. 情绪稳定性：TTS 情绪标签不在相邻句之间反复横跳（用户明确要求）。
4. 舞台演出：上下场节奏、背景/SE/BGM/环境色/转场。

## 已确认的根因

1. **台词轮转**：提示词“同一角色连续多为 1~2 句”被模型理解成严格一人一句；97.9% 的连续段只有 1 句。
2. **句长**：提示词同时写“7~25 字”和“单行 26 字”，模型取短边；`longShare` 为 0。
3. **情绪**：台词轮直接让模型逐句产 emotion，模型按每句语气标注，`changesPer40=33`、`runMean=1.18`。
4. **动作**：表演轮要求“每句 1 个动作”，模型 100% 一句一动作，无动作句为 0。
5. **舞台**：`composeStory` 固定双人 Left/Right、开场同时入场、结尾同时退场；官方是逐说话人上下场，
   78% 的台词只有一人在场。当前 `stageMean=2.00`、`soloShare=0`。
6. **演出层**：AI 只选一张背景、无 SE、无环境色、无转场；官方每 40 句约 3 个 SE、1.4 张背景。

## 分阶段实施

### Phase 1：台词与情绪（已完成第一版）

- [x] 重写台词轮提示词：句长目标、两行比例、短反应数量、连续说话段、省略号/问句比例。
- [x] 用 `turns` 结构替代扁平 `lines`：一个角色一次发言 = 一个 turn，天然产生 2~3 句连续。
- [x] 增加独立“情绪标注”轮：temperature 0.2、带完整上下文、按段落标注、只允许 6 标签。
- [x] 情绪后处理 `stabilizeEmotions`：同说话人最短连续 3 句；相邻段同标签合并；全片切换上限；
      单句例外只在强烈转折时保留；失败回退“平静”。
- [x] 表演轮：动作预算（约 1.0/句、20% 无动作、听者反应约 1/5），去掉“每句必须动作”的暗示。
- [x] 听者反应硬预算 20%：官方大部分台词只有一人在场，听者反应集中在换人/情绪转折处。
- [x] `condenseDialogue`：模型多写的同角色短句并回一条，只合并不改字，拉长平均句长。
- [x] `sanitizeDisplayText`：优先在标点/空格后折行，避免把中文词拦腰截断。

### Phase 2：舞台调度（已实现并抽样渲染）

- [x] `composeStory` 支持“逐说话人上下场”：默认只有说话者在场（Center），需要听者反应时双人

- [x] `planPresence`：发言段第一句有听者反应才双人同场，其余单人；保证至少一段双人同框。
- [x] 开场先 1 人，第二人随后入场；结尾按官方习惯退场。
- [x] 背景 1~2 张 + 环境色；第二张背景用短黑场包住。SE 暂不做（资源目录没有 SE 描述表）。

## 当前进度（2026-11-08 03:10）

- 官方基线：40 活动 / 328 集 / 48 个 40 句双人窗口，报告在 `msst-ai-lab/official-baseline.json`。
- 评测命令已固定；`scripts/stories/ai-eval.mjs` 直连 LLM，不占渲染端口。
- 8 场景回归（phase20，thinking off，最终参数）：
  - 句数 42.1、平均句长 18.83、p90 32.1、>26 字 23.9%、短反应 14.6%、问句 17.9%、省略号 50.0%。
  - 动作 0.81/句、无动作 18.6%、听者反应 12.1%（官方 0.79 / 20.9% / 38.8%）。
  - 情绪切换 3.82/40、连续段 8.6（官方表情级 18.8/2.2；TTS 级刻意更稳）。
  - 舞台：同场 1.33、单人 66.6%、上场 20.9/40、下场 19.7/40、背景变化 0.97/40、BGM 变化 1.44/40。
  - 估算时长 189 秒（官方窗口约 177 秒），总字数 793（官方约 746）。
- 台词轮改成“长短明显起伏”：约 45% turn 只有 1 条、约 1/5 两条、其余 3~6 条且至少 2 个
  6 条以上；JSON 样例同时放单条 turn 与 6 条 turn。连续说话段均值 2.17（官方 2.4），
  ≥4 句连续段 8.7%（官方 13%）。
- 长度预算按官方折算：3 分钟 48 句上限（16 句/分钟）、下限 750 字；实测 42 句 / 793 字 / 189 秒。
- 修正省略号统计口径：`softenPunctuation` 之前把破折号也算作“已有省略号”，导致破折号多的场次
  不再转换；现在只认 `…`/`...`，与指标一致，省略号占比从 41% 提到 50%（官方 58%）。
- 已知差距：单人发言段占比 29% vs 官方 55%。实验过把提示词拉到“55% 单条”，单人段能到 54%，
  但长段几乎消失（≥4 句连续段 4%）、总字数掉到 679；当前取中间值，优先保住 3 分钟体量与长段。
  thinking on 单场约 2~3 分钟，thinking off 约 25 秒。
- 回归：`npm test` 75 项全过；`npm run test:stories` 2 项全过（官方基线 + AI 质量门）。
